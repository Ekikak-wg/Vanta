## Что умеет

- **Меню поверх игры по Alt+Z** — панель у левого края экрана во всю высоту, закрывается по Esc, повторному Alt+Z или клику мимо. После закрытия фокус возвращается в игру.
- **Мгновенный повтор** — включить буфер, сохранить последние 3 секунды … 5 минут одной кнопкой или сочетанием клавиш. Сохранение не прерывает обычную запись и стрим.
- **Запись** — старт/стоп с таймером, папка записей и выбор новой папки прямо из меню.
- **Клипы** — галерея повторов и записей с миниатюрами и предпросмотром; обрезка (без потери качества или точно по кадру, с сохранением всех звуковых дорожек), переименование и удаление в Корзину.
- **Индикатор записи** — маленькая метка REC с таймером (по желанию — и «ПОВТОР») в углу экрана. В запись и демонстрацию не попадает, мышь пропускает.
- **Что попадает в запись** — две кнопки:
  - **Только игра** — пишется только окно игры: Alt+Tab, рабочий стол и другие программы в ролик не попадут;
  - **Игра и экран** — пишется весь монитор.
- **Игры находятся сами** — игры из Steam, Epic, Riot, GOG, Ubisoft, EA и Xbox, полноэкранные 3D-окна и ваш список «Мои игры». Захват игры в OBS переключается на окно найденной игры (работает в полноэкранном, оконном и безрамочном режимах), сцена — на «Только игра»; после закрытия игры возвращаются прежние сцена и захват. Для каждой игры можно задать свой режим и курсор.
- **Звук** — микшер прямо в меню: громкость, вкл/выкл, дорожки 1–6 и задержка для каждого источника; кнопка «Разделить звук по дорожкам» (общий, игра, микрофон, Discord, рабочий стол); запись звука всех программ, только выбранных или всех, кроме выбранных; дополнительные микрофоны и устройства вывода.
- **Не записывать приложения** — выберите Telegram, Discord, браузер и т. п.: пока их окно видно на экране (в том числе миниатюрой в Alt+Tab), захват монитора временно выключается и в записи остаётся только игра. Запись при этом не останавливается.
- **Горячие клавиши** — для каждого действия своё сочетание или никакого. Меню предупредит, если сочетание занято другой программой или совпадает с клавишей самого OBS.
- **Настройки записи** — длительность повтора, разрешение, FPS, а для NVENC ещё битрейт и профиль кодирования (экономичный / сбалансированный / качественный). Неудачное применение откатывается.
- **Невидимо для зрителей** — меню и его уведомления исключены из захвата экрана: их нет ни в записи OBS, ни в демонстрации Discord.
- **Работает в фоне** — запускается вместе с Windows в трей и сам поднимает OBS свёрнутым в трей. Если OBS упал (а не был закрыт вами), меню запускает его снова и включает буфер повтора. Буфер, выключенный вами вручную, меню не трогает.
- **Диагностика** — предупреждает, если кодировщик не успевает (пропуск кадров), видеокарта перегружена, OBS не отвечает или на диске записей меньше 5 ГБ. Предупреждения — уведомлением, которое не попадает в запись; всё пишется в журнал без паролей и настроек.
- **Лёгкое** — ~0,3 МБ, без Electron и браузера, без внедрения в игры. Работает от событий OBS и Windows; периодически — только статистика OBS раз в 10 с (пока OBS подключён), страховочная проверка окон исключённых приложений раз в 1,5 с и попытка подключиться к закрытому OBS раз в 3 с.

## Установка

1. Установите [OBS Studio](https://obsproject.com/download) 30 или новее.
2. Скачайте и запустите [**ReplayOBS-Setup.exe**](https://github.com/erteterya/Replay-OBS/raw/main/dist/ReplayOBS-Setup.exe). Права администратора не нужны: программа ставится в `%LOCALAPPDATA%\Programs\Replay OBS`.
3. Установщик может включить WebSocket-сервер OBS (через него меню управляет OBS). Если сервер уже включён, настройки не меняются; если нет — создаётся случайный пароль. Для этого шага OBS нужно закрыть.
4. В OBS включите буфер повтора: **Настройки → Вывод → Буфер повтора → Включить** и задайте длительность.
5. Нажмите **Alt+Z**.

> Windows SmartScreen может предупредить о неизвестном издателе — установщик не подписан сертификатом. Исходники и сборка открыты, см. «Сборка из исходников».

Установщик **не трогает** профили, сцены и настройки записи OBS. Удаление — через «Параметры → Приложения» (или повторный запуск установщика → «Удалить»); настройки OBS при этом остаются как есть.

## Как подготовить сцены для режимов

Меню само находит сцены по содержимому:

| Кнопка | Какая сцена нужна в OBS |
|---|---|
| **Только игра** | сцена с источником «Захват игры» и **без** «Захвата экрана» |
| **Игра и экран** | сцена с источником «Захват экрана» (можно положить «Захват игры» под ним — он покажется, пока скрыт экран) |

Скрытие приложений работает в сцене с «Захватом экрана»: меню выключает этот источник, пока исключённое окно видно, и включает обратно, когда окно свёрнуто, закрыто или перекрыто.

## Горячие клавиши по умолчанию

| Действие | Сочетание |
|---|---|
| Открыть / закрыть меню | Alt+Z |
| Сохранить повтор | Ctrl+Alt+F10 |
| Повтор вкл/выкл, запись, режимы, микрофон, клипы | не заданы — назначьте в меню |

Если Alt+Z уже занят оверлеем NVIDIA, назначьте другое сочетание в меню → «Горячие клавиши» или откройте меню из значка в трее.

## Игры

Меню → **Настройки → Игры**.

**Что считается игрой** (по порядку): программа из «Не считать играми» — никогда; из «Мои игры» — всегда; браузеры, плееры, мессенджеры, лаунчеры и системные окна — нет; программа из папки игровой библиотеки (`steamapps\common`, Epic Games, Riot Games, GOG, Ubisoft, EA Games, XboxGames) — да; окно во весь монитор с Direct3D, Vulkan или OpenGL — да (у процессов под защитой античита модули прочитать нельзя — тогда достаточно окна во весь монитор).

**Когда игра найдена** (она становится активным окном):
1. Все источники «Захват игры» в OBS переключаются на окно этой игры — режим «Захват отдельного окна» с совпадением по exe. Так OBS захватывает игры в полноэкранном, оконном и безрамочном режимах. Источник, уже настроенный на эту игру, не трогается, чтобы захват не перецеплялся.
2. Сцена переключается по профилю игры или по умолчанию: «Только игра», «Игра и экран» или «Не менять сцену». Во время трансляции сцену с заставкой меню не меняет.
3. Источник «Захват игры» без рамки масштабирования растягивается на весь кадр с сохранением пропорций — смена разрешения в игре не оставит картинку маленькой.

Alt+Tab игру не «отпускает»: она остаётся активной, пока запущен её процесс. **После закрытия игры** возвращается прежняя сцена (если вы не сменили её вручную) и прежние настройки захвата игры. Если меню закрылось во время игры, возврат произойдёт при следующем подключении к OBS.

## Звук

Меню → **Настройки → Звук**.

**Разделить звук по дорожкам** (нужен расширенный режим вывода OBS) — одна кнопка:

| Дорожка | Что на ней |
|---|---|
| 1 Общий | звук рабочего стола + микрофон (без двойного звука) |
| 2 Игра | звук игры — из источника «Захват игры» (включается «Захватывать звук») |
| 3 Микрофон | микрофон из настроек звука OBS |
| 4 Discord | источник «Discord — звук» (создаётся, если Discord установлен и такого источника нет) |
| 5 Рабочий стол | весь звук компьютера |

Дорожки 1–5 добавляются в запись и повтор; пустые названия дорожек заполняются, свои — не трогаются. Если список записываемых дорожек меняется, буфер повтора перезапускается (меню спросит).

**Микшер**: для каждого источника со звуком — громкость (−60…0 дБ), вкл/выкл, кнопки дорожек 1–6 и задержка звука в мс (для синхронизации). Источники, добавленные меню, можно убрать оттуда же.

**Звук программ** — три режима:
- **Весь звук компьютера** — как обычно в OBS.
- **Только выбранные программы** — звук рабочего стола убирается из записи, каждая программа из списка пишется своим источником «Звук · программа» (дорожки 1 и 5). Игра, Discord и микрофон остаются.
- **Весь звук, кроме выбранных** — то же, но источники создаются сами для каждой программы, которая выводит звук (проверка раз в 2 с), кроме списка. Игры, OBS и программы со своим источником пропускаются, чтобы звук не удваивался. Системные звуки Windows в этом режиме не пишутся.

Windows не умеет вычитать программу из общего звука, поэтому исключение звука сделано через захват звука отдельных программ (OBS 30+, Windows 10 2004+). Возврат к «Весь звук компьютера» возвращает прежние дорожки и удаляет созданные меню источники.

**Микрофоны и устройства вывода**: «Добавить» создаёт отдельный источник для выбранного устройства (микрофон — дорожки 1 и 3, вывод — 1 и 5).

**Проверка синхронизации звука и видео** — `bin\AvSyncCheck.exe` (собирается вместе с меню, нужен ffmpeg в PATH):
1. В OBS выберите сцену с захватом экрана.
2. `AvSyncCheck signal 8` — 8 секунд вспышек в левом верхнем углу экрана с писком.
3. Сохраните повтор и выполните `AvSyncCheck analyze "<файл повтора>"`.

Инструмент найдёт вспышки и писки и покажет расхождение. Точность — около ±1 кадра. Если звук заметно отстаёт или опережает, задайте задержку источника в микшере.

## Приватность

Меню → **Настройки → Не записывать приложения**.

- **Исключённые программы.** В режиме «Игра и экран», пока окно такой программы видно на мониторе (или её миниатюра в Alt+Tab, Win+Tab, превью панели задач), захват экрана скрывается — в записи остаётся игра. Меню следит за окнами по событиям Windows; на процессы исключённых программ ставятся отдельные хуки перемещения и порядка окон, поэтому замечается и окно, которое вынесли на экран без активации.
- **Уведомления Windows.** Их рисует сама Windows (ShellExperienceHost), а не приложение-отправитель, поэтому исключение приложения их не скрывает. Флажок «Скрывать всплывающие уведомления Windows» скрывает экран на время любого такого уведомления.
- **Строгая защита.** Без неё меню скрывает окно за 10–30 мс, и 1–2 кадра при 60 к/с могут попасть в запись. Со строгой защитой захват экрана идёт с задержкой 100 мс (фильтр OBS «Задержка рендеринга»), а скрытие — «шторкой» поверх него (служебная сцена «Replay · скрытие»: тёмный фон и захват игры). Меню успевает закрыть окно до того, как его кадры дойдут до записи; «шторка» снимается только через 250 мс после того, как окно исчезло. Звук всех источников сдвигается на те же 100 мс, чтобы не опережать картинку; в режиме «Только игра» звук будет отставать на 100 мс — на слух это незаметно. Выключение убирает фильтр, «шторку» и сдвиг звука (ваши ручные правки задержки сохраняются).
- **Правила для игр.** В «Моих играх» для каждой игры: «как обычно», «скрывать весь экран, пока идёт игра» или «не скрывать программы во время игры».
- **Предупреждения.** Меню честно пишет, когда скрыть нельзя: окно исключённой программы захвачено отдельным источником напрямую; захват экрана лежит во вложенной сцене или группе; захват игры записывает сторонние оверлеи (Discord, Steam…); исключённая программа — это сама игра; в текущей сцене нет захвата экрана (тогда скрывать нечего).

**Проверка утечек** — `bin\PrivacyLeakTest.exe` (нужен ffmpeg в PATH): добавьте `PrivacyLeakTest.exe` в исключения, выберите сцену с захватом экрана, выполните `PrivacyLeakTest run` (пурпурные окна: обычное, всплывающее без активации, вынос на экран без активации), сохраните повтор и выполните `PrivacyLeakTest analyze "<файл повтора>"` — инструмент посчитает кадры, где окно попало в запись.

## Клипы

Меню → **Клипы и записи** (или значок в трее → «Клипы»). Показываются видео из папки записей OBS, новые сверху, по 40 штук.

- **Предпросмотр.** Щелчок по клипу открывает проигрыватель. Звук предпросмотра по умолчанию выключен: картинка меню в запись не попадает, а звук попал бы в дорожку «Звук рабочего стола».
- **Обрезка.** «Начало здесь» / «Конец здесь» задают отрезок по текущему месту; отрезок сохраняется **новым файлом** рядом («… (обрезка).mp4»), исходный не меняется. По умолчанию — без перекодирования: быстро и без потери качества, все звуковые дорожки сохраняются, но начало сдвигается к ближайшему ключевому кадру (у OBS обычно каждые 2 с). «Точно по кадру» перекодирует видео (NVENC, без NVIDIA — процессором) и звук всех дорожек в AAC. «Сохранить в MP4» — для Discord и телефона (MKV там не воспроизводится). Повторное нажатие кнопки — отмена.
- **Переименование** — расширение сохраняется; недопустимые для Windows имена и занятые имена не принимаются.
- **Удаление** — только в Корзину, с подтверждением.
- Файл, который OBS ещё пишет, не обрезается, не переименовывается и не удаляется.

Для обрезки нужен **ffmpeg** — в комплект он не входит. Меню ищет его рядом с собой, в PATH и в пакетах winget; проще всего установить командой `winget install Gyan.FFmpeg` или указать ffmpeg.exe кнопкой в галерее. Остальное работает без него. Миниатюры и длительность берутся у Windows (как в Проводнике); если Windows их не знает, а ffmpeg есть — через ffmpeg.

## Фоновая работа и журнал

Меню → **Настройки → Фоновая работа**:

| Флажок | Что делает |
|---|---|
| Запускать OBS вместе с меню | при старте меню запускает OBS свёрнутым в трей (`--minimize-to-tray --startreplaybuffer`); после сбоя OBS — запускает снова (не чаще 3 раз за 10 минут) |
| Держать мгновенный повтор включённым | после перезапуска OBS включает буфер; если вы выключили буфер сами — оставляет выключенным |
| Предупреждать о пропуске кадров и нехватке места | раз в 10 с сверяет статистику OBS; одно и то же предупреждение — не чаще раза в 5 минут |

**Индикатор в углу экрана**: «Не показывать», «Только во время записи» (по умолчанию) или «Запись и повтор»; угол — любой. Индикатор исключён из захвата, пропускает щелчки мыши и не забирает фокус. Над игрой в эксклюзивном полноэкранном режиме его не видно.

Автозапуск сделан двумя независимыми способами — запись в разделе `Run` реестра и ярлык в папке «Автозагрузка»: на некоторых системах Windows без видимых причин пропускает запись `Run`. Если сработают оба, вторая копия меню сразу закрывается; в журнале видно, каким способом меню запустилось.

После сбоя OBS при следующем запуске спрашивает про безопасный режим модальным окном; у OBS, запущенного в трее, это окно не видно, и он зависает. Поэтому перед запуском (только когда OBS точно не работает) меню удаляет устаревшие отметки сбоя из `%APPDATA%\obs-studio\.sentinel`.

Журнал: `%LOCALAPPDATA%\Programs\Replay OBS\logs\replay-overlay.log` (меню → «Открыть журнал» или значок в трее). Подключения, буфер, сохранения, предупреждения и сводка раз в 5 минут: FPS, загрузка, память, пропуски кадров. Паролей и настроек OBS в журнале нет. При 1 МБ журнал переносится в `replay-overlay.1.log`.

## Ограничения

- Меню показывается поверх оконных и безрамочных игр. В **эксклюзивном полноэкранном** режиме игра может свернуться — переключите её в «Без рамки».
- Без строгой защиты скрытие приложений срабатывает примерно за 10–30 мс после появления окна: 1–2 кадра при 60 FPS могут попасть в запись. Строгая защита это закрывает ценой задержки экрана и звука на 100 мс.
- Звук исключённых приложений остаётся в дорожке «Звук рабочего стола»; системные уведомления Windows принадлежат Windows, а не приложению.
- Обрезка клипов требует установленного ffmpeg. Встроенный проигрыватель использует кодеки Windows: если Windows не умеет воспроизводить файл (например, HEVC или AV1 без расширения из Microsoft Store), предпросмотра не будет, но обрезка и остальное работают.
- Битрейт и профиль кодирования меняются из меню только для NVENC в расширенном режиме вывода; для остальных кодировщиков — в настройках OBS.
- WebSocket-сервер OBS слушает сеть, вход защищён паролем. Меню подключается только к `127.0.0.1` и читает пароль из локальной настройки OBS — он никуда не передаётся.

## Сборка из исходников

Нужен только Windows: используется компилятор C# из .NET Framework 4.x, который уже есть в системе. Visual Studio и .NET SDK не требуются.

```powershell
.\build.ps1                 # bin\ReplayOverlay.exe и bin\ReplayOBS-Setup.exe
.\build.ps1 -Test           # + автотесты: клиент WebSocket и установщик в изолированной папке
.\build.ps1 -Test -Desktop  # + тест видимости окон (ненадолго открывает «Таблицу символов») и страницы клипов (окно за экраном)
```

Тихая установка: `ReplayOBS-Setup.exe --silent [--no-websocket] [--no-autostart] [--no-obs-launch] [--desktop] [--no-launch]`, удаление: `--uninstall --silent`.

План развития — в [ROADMAP.md](ROADMAP.md).

## Устройство

```
src/Overlay/   меню: WPF, без внешних зависимостей
  Program.cs     окно, действия, горячие клавиши, режимы, применение настроек
  ObsClient.cs   клиент obs-websocket v5 (вход по challenge/salt, запросы, события, переподключение)
  Privacy.cs     слежение за окнами исключённых приложений (WinEvent-хуки + учёт перекрытия окон)
  Hotkeys.cs     сочетания клавиш и чтение клавиш самого OBS для предупреждений
  ObsConfig.cs   где лежат файлы OBS и сам OBS
  Diagnostics.cs журнал и разбор статистики OBS (пропуски кадров, место на диске)
  Games.cs       распознавание игр, перенаправление захвата игры, возврат после игры
  Audio.cs       дорожки, звук программ (сеансы Windows Core Audio), устройства
  Clips.cs       список клипов, имена, Корзина, ffmpeg (обрезка, миниатюры), миниатюры Windows
  Gallery.cs     страница «Клипы»: проигрыватель, отрезок, переименование; индикатор в меню
  Indicator.cs   индикатор REC / ПОВТОР в углу экрана
src/Setup/     установщик: один exe, меню вшито внутрь
tests/         автотесты
tools/         генератор значка, AvSyncCheck — синхронизация звука и видео, PrivacyLeakTest — утечки кадров
```
