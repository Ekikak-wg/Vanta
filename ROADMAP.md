Отметки — по фактически сделанному и проверенному. «Частично» — пояснение в скобках.

## v1.1 — Стабильность и фоновая работа

- [x] Скрытый запуск OBS вместе с Replay OBS (свёрнутым в трей, с буфером повтора)
- [x] Автозапуск вместе с Windows и сворачивание в трей
- [x] Автоматическое переподключение к OBS WebSocket
- [x] Восстановление буфера после падения или перезапуска OBS (при зависании — предупреждение; принудительно OBS не закрывается)
- [ ] Проверка длительной работы 3–6 часов (журнал со сводкой раз в 5 минут готов)
- [ ] Корректная работа одновременно с Discord и записью (частично: буфер и запись вместе с демонстрацией игры в Discord проверены коротко)
- [x] Диагностика перегрузки кодировщика, пропущенных кадров, места на диске и зависания OBS
- [x] Безопасное управление конфигурацией OBS и WebSocket (резервные копии, атомарная запись, откат, пароль не перезаписывается)

## v1.4 — Приватность записи

- [x] Исключение выбранных приложений из видеозахвата
